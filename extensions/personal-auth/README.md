# 按说话的人使用自己的授权

看自己的 Lark 任务，以及 Meegle 的查看、待办、创建和修改，只用当前说话这个人的授权。别人的命令不会进这个目录。没有授权时直接说明做不到，不会改用别人的登录，也不会用机器人身份去查这个人的任务。

新建、修改、完成、重新打开、分配负责人和加备注仍然用机器人身份。对话里不能扫码，也不能改机器人的身份。

每个人的授权在运行目录的 `personal-auth/<这个人的标识>/` 下，不进 Git：

- `lark/hermes/config.json`：只给「看自己的任务」用。里面要有这个人自己的用户身份。机器人那份配置不算。
- `meegle-home/.meegle/`：只给这个人的 Meegle 用。第一次在对话里登录 Meegle 时，登录结果写到这里，不写到大家共用的目录。

以前留在聊天目录里的那份 Meegle 登录，启动这个扩展时会挪到 `personal-auth/_retired-shared/`。那里不对应任何人，之后的命令不会再用它。

容器启动时会放上这个扩展，以及镜像里的 Lark 和 Meegle 命令，不用再单独安装。已经在运行目录里的个人授权不会被覆盖。
