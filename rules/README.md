# 机器人规则模板

待定义 SOUL.md、AGENTS.md 与权限模板。只放通用规则和占位配置；真实管理员 ID、凭据和内部项目资料不提交。

## 专业写作技能

`skills/plain-language-writing/` 是 Hermes 原生本地技能，供需要交付或留档的项目文档、Issue、Lark Task、Meegle 任务正文、评论、验收记录和操作说明使用。它要求保留事实、范围、负责人、验收条件和未确定项，使用简洁专业的措辞，不把未执行内容写成已完成。

普通问候、闲聊和即时对话继续使用 `SOUL.md` 的语气；一条消息同时包含闲聊和工作正文时，只对工作正文加载这份技能。该技能不授予创建或修改外部任务的权限。运行端由部署状态目录的 `data/skills/` 自动发现，不改 Hermes Core。

## Lark Lingo 技能

`skills/lark-lingo/` 用于 Lark 词典 repo、分类、词条去重和草稿导入。它默认走受管机器人身份和可审核 draft 接口；需要用户身份、额外权限或直接发布时必须停下说明，不得静默借用个人授权。批量导入先生成稳定 `outer_id` 的 JSON 并完成去重；技能安装本身不创建词条。
